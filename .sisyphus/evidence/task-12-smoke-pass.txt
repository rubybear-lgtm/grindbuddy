# Task 12: Direct Cutover Smoke Script and Go/No-Go Runbook

## Smoke Script Created
- Location: `grind-buddy-v2/scripts/cutover-smoke.sh`
- Executable: Yes (chmod +x)

## Smoke Checks Implemented
1. Build artifacts check (manifest.json, assets directory)
2. PHP test suite (pest --compact)
3. TypeScript type check (npm run types:check)
4. ESLint check (npx eslint resources/)
5. Pint code style check (vendor/bin/pint --test)
6. Key unauthenticated routes (health, companies, login)
7. OAuth redirect initiation (Google, GitHub, unknown provider rejection)
8. Auth-protected route gating (dashboard, logbook, analytics redirect to login)
9. Email/password auth disabled (POST /login returns 404)
10. No legacy logs import (grind:import-catalog command exists)
11. Environment configuration (Google/GitHub placeholders, no Neon Auth vars)

## Go/No-Go Runbook

### Pre-Freeze
1. Verify all smoke checks pass: `bash scripts/cutover-smoke.sh`
2. Run catalog import: `php artisan grind:import-catalog --skip-orphans`
3. Verify catalog row counts match source snapshot
4. Verify zero legacy logs in target database

### Snapshot/Import
1. Take final catalog snapshot from source database
2. Run `php artisan grind:import-catalog` on target
3. Verify row counts: problems, companies, company_problems
4. Verify zero imported logs

### Deploy
1. Set APP_URL to production domain
2. Set DB_CONNECTION=pgsql and DB_ credentials
3. Set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET
4. Set GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET
5. Run `php artisan migrate --force`
6. Run `npm run build`
7. Run `bash scripts/cutover-smoke.sh https://your-production-url.com`

### Smoke
1. All smoke checks pass (exit 0)
2. OAuth login works with Google
3. OAuth login works with GitHub
4. Dashboard loads with catalog data
5. Logbook shows empty state for fresh users
6. Analytics shows empty state for fresh users
7. No legacy logs visible

### Switch Traffic
1. Update DNS/load balancer to point to new Laravel app
2. Monitor error rates for 15 minutes
3. Verify OAuth callbacks work on production domain

### Rollback Boundary
- If smoke checks fail: Do NOT switch traffic
- If OAuth login fails: Revert DNS to source SvelteKit app
- If catalog data is missing: Re-run import command
- If users see errors: Check Laravel logs, revert DNS if needed
